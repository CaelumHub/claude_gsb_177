控制流图（Control Flow Graph）

以真实字节码做前导指令（leader）分析切分基本块：跳转 / 条件跳转 / 返回指令的目标与下一指令都是新块的起点。 边直接由实发指令推导，因此 if 分支、while/for 循环回边、break/continue、提前 return 与函数尾返回 都能准确呈现；CALL 经栈模拟还原被调函数，递归显示为自环、互递归显示为跨函数调用边。 块标题与「字节码」页偏移（1 起）、行号完全对齐。

输入源码后点击「生成控制流图」

图例与阅读说明

顺序执行 / 无条件跳转（break 跳出） 条件分支（真 / 假两条边） 循环回边（回到条件处，含 continue） 返回到函数出口（含提前 return） 调用用户函数（跨泳道；自环=递归）
  • 每个函数一条泳道，最上方为 <main> 顶层；基本块 B0 从函数入口可达。
  • 块头标注字节码偏移区间（如 3–7）与源码行号区间，与「字节码 / 中间代码」页一致；跳转目标 → N 为目标指令的偏移。
  • 红底「不可达」块是 return 之后仍存在于字节码中的代码（如条件编译出的死跳转目标），仍完整画出以免漏边。
  • 逻辑短路（&& / ||）在字节码层也是条件跳转，图中以条件边如实呈现。
